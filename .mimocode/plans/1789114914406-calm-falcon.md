# eFTI Experts: Django to Jekyll Rewrite Plan

## Overview

Rewrite the eFTI Experts Django site (`~/Projects/efti_experts`) as a static Jekyll site (`~/Projects/homepage`), following the patterns from the reference project (`~/Projects/rendiportaal-homepage`).

**Key decisions:**
- English only (no i18n)
- Keep eFTI branding (Roboto font, `#4A58A6` accent color)
- Team members & projects stored in `_data/` YAML files
- Contact form via FormSubmit.co (serverless)
- Keep D3.js interactive map + AOS animations
- Deploy via GitHub Pages (CNAME file)

---

## Step 1: Project scaffolding & config

Create the base Jekyll project structure matching the reference pattern.

### Files to create:

- **`_config.yml`** — Site config with title, description, url, email, permalink style, jekyll-sitemap plugin, defaults for page scopes. No `languages` key (English only). Exclude build files (Gemfile, package.json, tailwind.config.js, build.sh, etc.)
- **`Gemfile`** — `gem "github-pages", group: :jekyll_plugins`
- **`package.json`** — Tailwind CSS dependencies (`tailwindcss@3`, `@tailwindcss/typography`)
- **`tailwind.config.js`** — Content paths: `_layouts/**/*.html`, `_includes/**/*.html`, `_pages/**/*.md`, `*.html`. Font family: `Roboto`. Plugin: `@tailwindcss/typography`
- **`build.sh`** — `npx tailwindcss@3 -i ./css/style.css -o ./css/tailwind.min.css --minify`
- **`CNAME`** — `eftiexperts.eu`
- **`robots.txt`** — Sitemap reference
- **`.gitignore`** — node_modules, .bundle, vendor, _site, Gemfile.lock, package-lock.json, etc.
- **`index.html`** — Root redirect to `/home/` (or just be the homepage directly — since no i18n, no language prefix needed)

## Step 3: CSS architecture

Follow reference pattern exactly:

- **`css/fonts.css`** — Self-hosted Roboto font @font-face declarations (matching the reference's `fonts.css` pattern, but with Roboto instead of Inter). Download Roboto woff2 files from Google Fonts and place in `/fonts/`
- **`css/style.css`** — Tailwind directives (`@tailwind base/components/utilities`) + custom `.prose` heading overrides + any eFTI-specific custom styles (video overlay, map styles, animations)
- **`css/tailwind.min.css`** — Generated by `build.sh` (pre-compiled, committed to repo)
- **`fonts/`** — Roboto woff2 files (regular 400, bold 700 minimum)

**Tailwind config customizations:**
- `fontFamily.sans`: `['Roboto', 'sans-serif']`
- Custom colors: `#4A58A6` (brand), `#EEEDFF` (light bg), `#475569` (section labels)

## Step 5: Includes (8 files)

All in `_includes/`, following reference patterns:

1. **`navbar.html`** — Sticky nav with logo, desktop links (from `_data/nav.yml`), mobile hamburger menu with JS toggle. No language switcher (English only). Adapted from both the Django navbar and the reference navbar.html include.

2. **`footer.html`** — Company info (VAT, address), email, LinkedIn, imprint link, copyright. Pattern from reference footer.

3. **`cookie-banner.html`** — GDPR cookie consent banner with accept/decline buttons using localStorage (matching the reference pattern, replacing Django's cookie-based approach with server-side logging).

4. **`contact-form.html`** — FormSubmit.co form with: name, email, phone (optional), inquiry type dropdown, message. Hidden fields for subject and captcha. Translated labels via variables (since no i18n, hardcode English).

5. **`service-card.html`** — Card with SVG icon (using `include.icon` path data), title, description. Styled with brand colors.

6. **`project-card.html`** — Card with image, title, truncated description, click-to-expand overlay. Matches the Django projects.html pattern.

7. **`member-card.html`** — Team member card with photo, name, title, truncated summary, "Read more" link triggering overlay. Matches the Django about_us.html pattern.

8. **`map.html`** — Self-contained D3.js Europe map include with GeoJSON loading, country coloring (eFTI4EU=blue, eFTI4ALL=yellow), tooltips, legend, responsive resize. Extracted from the Django home.html inline script.

## Step 6: Layouts (5 files)

All extend `default.html`, matching reference layout hierarchy:

### `_layouts/default.html`
Base HTML shell. Includes:
- `<head>`: charset, viewport, canonical, OpenGraph, Schema.org JSON-LD (Organization), favicons, fonts.css, tailwind.min.css, Google Analytics (consent-gated)
- `<body>`: navbar include, `<main>{{ content }}</main>`, footer include, cookie banner include
- Consent-gated GA loading script (matching reference pattern with localStorage)

### `_layouts/home.html`
Extends `default`. Renders:
- Full-screen hero section with video background, texture overlay, animated text, CTA buttons
- "Our Expertise" section with service highlights (5 items with SVG icons)
- "About Our Expertise" with stats (39 partners, 14 member states, 100% digital, expert delivery)
- "Key Projects" / "Our Initiatives" section with eFTI4ALL card
- European Operations section with D3.js map (include `map.html`)
- Team preview section with CTA
- AOS animations on scroll
- Fade-up hero overlay script
- Link to D3.js and AOS JS libraries

### `_layouts/page.html`
Extends `default`. Generic content page with title + prose content. Used for: imprint, contact.

### `_layouts/projects.html`
Extends `default`. Renders project cards grid from `site.data.projects` with click-to-expand overlay modal (matching Django projects.html).

### `_layouts/about.html`
Extends `default`. Renders:
- Company introduction section with stats sidebar
- Mission & Vision cards
- Team grid from `site.data.team` with click-to-expand overlay (matching Django about_us.html)
- Partnerships section (51 BIZ, Circle, Christian Lüpges)
- CTA section
